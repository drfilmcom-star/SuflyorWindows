# План переноса голосового ядра Suflyor

## Решение по распознаванию
Не использовать Windows Speech API и облачный ASR. Windows-версия должна работать локально через sherpa-onnx.

В Android-версии уже есть проверенная связка:
- `SherpaAsr.kt`: streaming Zipformer RU small int8, 16 kHz, CPU, два потока;
- `AsrEngine.kt`: контракт потокового распознавателя;
- `SessionEngine.kt`: микрофон → ASR → трекер → состояние сеанса;
- `ScriptTracker.kt`: сопоставление распознанных слов со сценарием и защита от ложных скачков;
- `SpeechLang.kt` и `TextNorm.kt`: нормализация русской речи и текста.

Использовать ту же модель и настройки, не подменять другой моделью без сравнительного теста.

## Поток данных
1. WASAPI/NAudio получает mono PCM с микрофона.
2. Audio pipeline приводит поток к 16 kHz float32 и передаёт чанки в sherpa-onnx.
3. Streaming recognizer выдаёт частичные гипотезы и финальные фрагменты.
4. Русская нормализация формирует список слов.
5. Портированный ScriptTracker определяет позицию в текущем сценарии.
6. UI обновляет позицию окна ведущего. Захват аудио и декодирование не выполняются в UI-потоке.

## Требования
- Полная работа без сети после установки.
- Модель загружается один раз на сеанс.
- Частичные гипотезы не должны вызывать скачки текста.
- Далёкий переход принимается только после подтверждения информативными словами.
- «Суфлёр заново» сбрасывает трекер к первому слову текущего блока и очищает контекст гипотезы.
- Ручной переход синхронизирует позицию трекера и сбрасывает устаревшие результаты.
- Ошибка микрофона/модели отображается явно.

## Этапы
1. Проверить NuGet sherpa-onnx на Windows 10/11 x64 и включить RU модель.
2. Подключить микрофон, ресемплинг и потоковое распознавание.
3. Перенести русскую нормализацию и ScriptTracker с тестами.
4. Связать трекер с окном ведущего, реализовать паузу и ручное позиционирование.
5. Добавить импорт сценариев и автономный установщик.
6. Проверить работу без интернета на реальной записи ведущего.

## Текущий статус
Подготовлен WPF-прототип .NET 8. Голосовое ядро ещё не интегрировано и не протестировано на Windows.
