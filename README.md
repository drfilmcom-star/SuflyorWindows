# Suflyor Windows — прототип для Windows 10/11

Настольная версия телесуфлёра. Целевые ОС: **Windows 10 x64 и Windows 11 x64**. Windows 7 исключена.

## Реализовано в текущем прототипе
- Редактор сценария и открытие TXT.
- Разделение сценария маркерами `[[БЛОК]]`.
- Отдельное окно ведущего, которое можно перенести на второй монитор.
- Полноэкранный режим и изменение размера шрифта.
- Команда «Суфлёр заново» возвращает к началу текущего блока.

## Техническая основа
- WPF, .NET 8, x64.
- NuGet-зависимость `org.k2fsa.sherpa.onnx` добавлена для следующего этапа интеграции локального ASR.
- Целевой русский ASR — тот же streaming Zipformer RU small int8, который используется Android-версией Suflyor.
- Интернет не должен требоваться во время распознавания: модель и нативные библиотеки будут поставляться вместе с приложением.

## Ещё не реализовано
- Захват микрофона и потоковая передача аудио в sherpa-onnx.
- Перенос и адаптация алгоритма ScriptTracker и русской нормализации из Android-версии.
- Автоматическая синхронизация текста с произносимой речью.
- Импорт DOCX/RTF/PDF.
- Установщик и автономный пакет модели.

## Сборка
Проект собирается через .NET 8 SDK. Visual Studio IDE не обязательна. GitHub Actions выполняет Windows x64 сборку и публикацию артефакта.

## Маркер блока
Поставьте `[[БЛОК]]` отдельной строкой перед каждым блоком. «Суфлёр заново» возвращает к началу активного блока, а не всего сценария.
